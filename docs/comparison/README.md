# volcomp quality comparison on raw scroll CT

512^3 cubes of ORIGINAL uint8 CT (the open-data bucket's uncompressed level-0 chunks) from four ESRF scans at four voxel sizes, encoded at q = 1 .. 32 (128^3 chunks) and decoded without deblocking. Every version has nine 512^2 lossless PNG views: the six cube faces (`z0 z511 y0 y511 x0 x511`) and the three centre planes (`zmid ymid xmid`); `<view>_all.png` puts raw and the six q levels side by side. Generated by `tools/compare_images.py`; numbers in `report.json`.
